# What Is Markdown
Markdown is a "markup" language that is a lightweight way to create formatted text documents by using plain text and an interpreter. Created in 2004 by John Gruber, it has spread throughout computer science circles.

The purpose of Markdown is really simple: It lets you use the regular characters on your keyboard which you already use while typing out things like emails, to make fancy formatting of text for the web. The name of that HTML format that's used to make web pages stands for HyperText Markup Language. The word “markup” there means you’re “marking up” your text with all kinds of special characters. (see [Anil Dash's article](https://www.anildash.com/2026/01/09/how-markdown-took-over-the-world/) for a lot more history on Markdown)

## Changing Fonts
In markdown, fonts can be modified like in a normal document you can **bold**, *italics*, or ***bold and underlined***. You can also only bold or italics portions of words like super**man**. 

## Bullets and Lists 
You can create bullets and numbered lists with "-" and "1.". To create an sub-item of a list add a tab before the number. Example of lists: 

1. Item 1
2. Item 2
    1. Sub-Item 1
    2. Sub-Item 2
3. Item 3

- Bullet 1
- Bullet 2
    - Sub-bullet 1
    - Sub-bullet 2
- Bullet 3

## Hyperlinks
Hyperlinks can be added in with the format [] contains the text you want the reader to see and () with the link you want the reader to follow when they click on it. For example, if you want to point to Octobot's 2026 robot code you could give them this link: [Octane's Code](https://github.com/Octobots9084/Octane-2026).
